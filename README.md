# 📦 Análise de Dados de Logística — Power BI

Dashboard de análise de entregas com filtros por ano (2019/2020), canais, regiões e status de entrega.

---

## Visão geral

| Métrica | Valor |
|--------|-------|
| Total de Entregas | 21 Mil |
| Entregas no Prazo | 18 Mil |
| Entregas com Atraso | 2.563 |

---

## Páginas do dashboard

- **KPIs principais** — Total de entregas e entregas no prazo
- **Entregas no prazo por canal** — Ranking dos canais de entrega
- **Entregas por mês** — Evolução mensal (jan–ago)
- **Percentual por equipe** — Norte, Sudeste, Nordeste, Sul, Internet, Televendas, Venda Direta
- **Status das entregas** — Antecipado (71,93%), No Prazo (15,88%), Atrasado (12,19%)
- **Atrasos por cidade** — Tabela com ranking de cidades com mais atrasos

---

## Ferramentas

- Power BI Desktop
- DAX para medidas e KPIs

---

## Como abrir

1. Instale o [Power BI Desktop](https://powerbi.microsoft.com/pt-br/desktop/)
2. Abra o arquivo `.pbix` do projeto
3. Use os botões **2019 / 2020** no canto superior para filtrar por ano
